# 雾杉小屋 · Mistpine Cabin

一个可以直接双击打开的 **3D 森林小屋** 网页。整座森林、木屋、灯火、篝火与天气都在浏览器里实时渲染，所有材质、贴图、音效都由本地代码生成，无需联网。

## 打开方式

双击 `index.html` 即可。

建议使用较新的 **Chrome / Edge / Safari**，并保持浏览器硬件加速开启。

## 可以做什么

- **拖拽**：环绕木屋，看看森林四周
- **滚轮 / 双指捏合**：靠近或远离
- **点击木门**：走近木屋，门会打开，能看见暖融融的房间
- **点击窗户**：开关小屋灯火
- **点击篝火**：点燃或熄灭篝火，火光会实时照亮周围
- **底部控制栏**：切换灯火、篝火、天气（晴 / 雨 / 雪）、木门、森林环境声
- **右上角**：重置视角、全屏
- **键盘快捷键**：`L` 灯火 · `F` 篝火 · `W` 天气 · `D` 木门 · `M` 环境声 · `R` 重置视角

## 技术说明

- 低多边形、手绘感的美术方向，冷暖对比的蓝调森林
- 程序化材质：木纹标志、屋顶瓦片、窗内布帘、月亮、雾、雨雪粒子
- 自建轨道相机，带阻尼、自动慢速环绕和移动端双指缩放
- 自建 Web Audio 环境声：风、虫鸣、雨声、木柴噼啪、远处猫头鹰
- 无外部图片、字体或音频依赖；所有资源都在此文件夹内
